Student Utilities – Python Unit Testing

📌 Project Overview

This project is a simple Python utility module designed to manage basic student-related calculations. It includes functions to calculate average marks, check passing status, and assign grades based on student performance.

The project also demonstrates unit testing using Python's built-in "unittest" framework to verify the correctness of each function.

🚀 Features

- Calculate Average: Calculates the average of a list of student marks.
- Check Passing Status: Determines whether a student has passed based on the minimum passing mark (40).
- Grade Assignment: Assigns grades according to the student's average marks.
- Unit Testing: Uses Python's "unittest" module to test all utility functions.

⚙️ How to Run the Project

1. Clone the repository

git clone YOUR_GITHUB_REPOSITORY_URL

2. Navigate to the project directory

cd Student-Utilities

3. Run the Python program

python student_utils.py

4. Run unit tests

python -m unittest test_student_utils.py

🧪 Unit Testing

The project includes test cases to verify:

- Average calculation for multiple marks.
- Average calculation for a single mark.
- Passing marks above, at, and below the pass mark.
- Grade assignment for Distinction, First, Second, and Fail.

All test cases are designed using Python's built-in "unittest" framework.
